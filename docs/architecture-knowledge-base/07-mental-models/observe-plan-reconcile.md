# Observe → Plan → Reconcile

Think of the system as a thermostat.

## Intent

The desired temperature represents desired configuration.

## Observation

The sensor reports the actual temperature.

## Planning

The planner determines what the desired runtime should be.

## Reconciliation

The reconciler compares desired and actual conditions.

## Execution

The heater or cooler performs the minimal required action.

## Feedback

The system observes again and repeats.

The control loop never assumes that a previous operation succeeded.
