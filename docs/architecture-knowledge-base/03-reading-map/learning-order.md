# Suggested Learning Order

## Stage 1 — Software Design Foundations

Focus:

- cohesion,
- coupling,
- information hiding,
- responsibility assignment,
- deep modules.

## Stage 2 — Architecture Documentation

Focus:

- ADRs,
- context and consequence,
- tradeoff communication,
- architecture diagrams.

## Stage 3 — Declarative and Control-Loop Systems

Focus:

- desired state,
- observed state,
- planning,
- reconciliation,
- idempotence.

## Stage 4 — Reliability and Operations

Focus:

- fail-closed behavior,
- diagnostics,
- structured logging,
- health models,
- recovery.

## Stage 5 — Distributed and Platform Systems

Focus:

- eventual consistency,
- controllers,
- schedulers,
- infrastructure orchestration,
- extensible provider models.
