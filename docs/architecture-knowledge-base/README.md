# Architecture Knowledge Base

This knowledge base preserves durable architectural knowledge for PathVeer and its IranDirect predecessor.

It exists to capture:

- architectural decisions;
- reusable patterns;
- mental models;
- project evolution;
- learning resources;
- engineering principles/checklists.

It is not the authority for current machine state or the immediate engineering blocker.

For AI continuation use:

1. repository root `AI-START-HERE.md`;
2. `AI/CURRENT.md`;
3. `AI/SESSION-PROTOCOL.md`.

## Working Rules

1. Journal entries are chronological and append-only.
2. ADRs record one significant decision per file.
3. Pattern pages describe reusable ideas rather than one implementation.
4. Current PathVeer architecture belongs in the PathVeer project page.
5. IranDirect project pages preserve legacy/historical architecture.
6. Reading-map entries explain why a resource matters.
7. Do not duplicate explanations across multiple authorities; link instead.
8. Historical documents preserve the terminology/truth of their time.
9. Current milestone/status belongs only in `AI/CURRENT.md`.
