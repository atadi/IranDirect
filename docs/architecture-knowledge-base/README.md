# Architecture Knowledge Base

This knowledge base grows alongside IranDirect.

Its purpose is to preserve:

- architectural decisions,
- reusable design patterns,
- learning resources,
- project evolution,
- mental models,
- engineering checklists.

## Working Rules

1. Journal entries are chronological and append-only.
2. ADRs record one significant decision per file.
3. Pattern pages describe reusable ideas, not project-specific implementation.
4. Project pages explain how those ideas were applied in IranDirect.
5. Reading-map entries must explain why a resource matters.
6. Every completed milestone should update the relevant knowledge artifacts.
7. Do not duplicate the same explanation across multiple files; link instead.
